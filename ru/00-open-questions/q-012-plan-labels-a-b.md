# Q-012 — Что значат «A» и «B» на плане SPEC §5

Кратко: Что значат «A» и «B» на плане SPEC §5?

## Рекомендация

Считать B меткой камеры B и ставить камеру там, где её задаёт SPEC §26 (C-009); отдельной зоны B не вводить.

## Почему важно

На плане главной кабины стоят метки `A` и `B` по бокам блока `MAIN WORK / VLOG CABIN`. В тексте SPEC описана только «Zone A — Main command / work / vlog station»; зона B нигде не определена. Если B — камера B, она противоречит описанию §26 (камера B в верхнем кормовом углу, а не сбоку на уровне кабины).

## Варианты

B — вторая рабочая зона; B — метка камеры B; метка — ошибка схемы.
