# Q-028 — Чистые расчёты для клиента — только через ENGAGE?

Кратко: Чистые расчёты для клиента — тоже через ENGAGE?

## Рекомендация

Закон не требует, требует проект Calder: всё, что делается для клиента, — только через `ENGAGE`.

## Почему важно

Влияет на число подъёмов к рычагу за вахту.

## Варианты

Закон не требует, требует проект Calder (рекомендация); или расчёты идут в `LOCAL` без подъёма.

## От чего зависит

D-013.
