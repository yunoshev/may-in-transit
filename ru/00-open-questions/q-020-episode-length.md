# Q-020 — Длительность эпизода

Кратко: Какой длины пост?

## Рекомендация

30–60 с по умолчанию, объясняющие посты длиннее.

## Почему важно

CONCEPT называет формулу «по умолчанию для шортса 30–60 секунд», но эпизоды 2, 3, 7, 9 нагружены графикой и объяснениями. Раздел [70-series](../70-series/index.md) не развивается, вопрос записан для полноты.

## Варианты

30–60 с для всех; формула «по умолчанию» с исключениями.

## От чего зависит

Решение пользователя о формате публикации.
