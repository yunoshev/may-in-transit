# Быт: стирка, уборка, отходы

Кратко: бытовая часть корабля, которая в основном скрыта: ограниченная стирка, небольшой шкаф для уборки и компактные герметичные хранилища для отходов. Задача страницы — дать обычные бытовые сцены и держать кабину в порядке: корабль мал, и Майя обязана оставаться организованной.

## Стирка (SPEC §18)

Полноразмерной бытовой стиральной машины не моделировать. Канонический подход:
- большая часть повседневной одежды рассчитана на долгую носку;
- точечная чистка пятен;
- протирание или паровая очистка;
- небольшой герметичный ящик для чистки ткани, который запускается для редких циклов.

Точная технология вымышленная. Система может оставаться в основном скрытой. Мешок для белья входит в [личное хранение](storage.md).

## Уборка (SPEC §19)

Моделировать небольшой шкаф для уборки с:
- салфетками;
- компактным пылесосом;
- чистящим средством для поверхностей;
- щёткой;
- мешками для отходов;
- масками-фильтрами;
- перчатками.

Это даёт обычные сцены обслуживания и уборки (камера B для уборки, см. [внутренние камеры](interior-cameras.md)).

## Отходы (SPEC §20)

Отходы делятся на:
- биологические;
- сухой мусор;
- упаковку;
- перерабатываемый или обрабатываемый материал;
- опасные отходы.

Использовать компактные герметичные ящики и канистры. Никакого случайного мусора, плавающего или лежащего по кабине. Корабль достаточно мал, чтобы Майя должна быть организованной.

- Биологические отходы идут из санузла: у него «сервисный доступ к отходам» и закрытая обработка ([санузел](hygiene.md)).
- В камбузе есть ящик для органики и мешок для отходов ([камбуз](galley.md)).
- На сервисной стене есть надпись `WASTE PROC` ([сервисная стена](service-wall.md)); полный переработчик отходов подразумевается, а не моделируется (SPEC §34).
- Крупное хранение отходов может находиться в [служебном модуле](../exterior/service-pod.md).

## Что раскрыть при углублении
- Карта мест хранения отходов: где каждая из пяти категорий, в каких ящиках, как часто выносится.
- Принцип работы ящика для чистки ткани: что это за цикл и где расположен.
- Список содержимого шкафа для уборки с положением в кабине.
- Связь отходов с водным и воздушным циклами ([жизнеобеспечение](../systems/life-support.md), [вода](../systems/water.md)).
- Сцены обслуживания и уборки для камеры B, привязка к [быту Майи](../../40-characters/maya-daily-life.md).
- Как отходы влияют на балансировку при их перемещении ([служебный модуль](../exterior/service-pod.md)).

## Основания
> [!verified] Проверено
> Обращение с отходами — одна из базовых функций бортовых систем жизнеобеспечения ([NASA — ECLSS](https://www.nasa.gov/reference/environmental-control-and-life-support-systems-eclss/)). Источник: sources/maya_ari_ship_3d_build_spec.md §38.

> [!fiction] Вымысел
> Компактные душ и стирка не являются установленными возможностями сегодняшнего дня (SPEC §39); точная технология стирки вымышленная (SPEC §18).

> [!production] Решение для производства
> Никакой полной стиральной машины и никакого мусора по кабине: система по большей части скрыта, а уборка даёт простые бытовые сцены (SPEC §18–§20).

## Открытые вопросы
- Как именно работает «чистка ткани»: пар, ультразвук, химия, и сколько времени занимает цикл.
- Где хранятся опасные отходы.
- Куда отходы уходят из кабины: хранение в кабине или перенос в служебный модуль.
